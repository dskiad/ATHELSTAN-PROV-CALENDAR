Connect directly to GitHub

Create a token once, then use it here to publish your calendar. Your browser sends the token directly to GitHub and keeps it in this tab until you disconnect or close the tab.

  1. Open Create a GitHub token ↗ and sign in to dskiad.
  2. For Repository access, choose Only select repositories → ATHELSTAN-PROV-CALENDAR.
  3. Under repository permissions, confirm Contents: Read and write, then click Generate token.
  4. Copy the token and paste it into the field below.

Enter the token here in the editor. Treat it like a password.
